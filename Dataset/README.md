# 📂 Dataset

This folder contains the raw CSV files used for the Hotel Membership & Booking Analysis project.

## 📊 Dataset Tables

| File | Description |
|---|---|
| `member.csv` | Contains member details such as Member ID, Name, Join Date, and Subsidiary. |
| `membership1.csv` | Contains membership details including membership product, expiry date, and status. |
| `bookings.csv` | Contains hotel booking information including booking date, check-in date, hotel, and membership. |
| `hotels.csv` | Contains hotel details including Hotel ID, Hotel Name, and City. |
| `transaction.csv` | Contains transaction details including amount and payment method. |
| `entitlements.csv` | Contains membership entitlement information. |
| `renewals.csv` | Contains membership renewal information. |

## 🔗 Relationships

The tables are connected through common keys such as:

- `MemberID`
- `MembershipID`
- `BookingID`
- `HotelID`

These relationships allow the data to be analyzed using SQL and Power BI.

## 🛠️ Data Usage

The CSV files were used for:

- SQL data analysis
- Business problem solving
- Revenue analysis
- Membership analysis
- Booking analysis
- Power BI dashboard development

> **Note:** The dataset is used for educational and analytical purposes.
