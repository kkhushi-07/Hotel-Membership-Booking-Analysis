# 📊 Power BI Dashboard

This folder contains the Power BI dashboard created for the **Hotel Membership & Booking Analysis** project.

The dashboard transforms SQL and relational database analysis into interactive visualizations and business KPIs.

---

## 🎯 Dashboard Objectives

The Power BI dashboard was created to:

- Monitor key business performance indicators.
- Analyze membership performance.
- Track hotel bookings and revenue.
- Understand membership status distribution.
- Analyze monthly revenue trends.
- Identify top-performing hotels and membership products.
- Provide interactive filtering for city-level analysis.

---

## 📌 Key Performance Indicators (KPIs)

The dashboard includes the following KPIs:

| KPI | Description |
|---|---|
| 👥 Total Members | Total number of members in the dataset |
| 💳 Active Memberships | Number of currently active memberships |
| 💰 Total Revenue | Total revenue generated from transactions |
| 🏨 Total Bookings | Total number of hotel bookings |
| 🔄 Total Renewals | Total number of membership renewals |

---

## 📈 Dashboard Visualizations

### 1. Monthly Revenue Trend

A line chart showing how total revenue changes month by month.

**Purpose:**  
Helps identify revenue trends and changes in business performance over time.

---

### 2. Membership Status Distribution

A donut chart showing the distribution of:

- Active memberships
- Expired memberships
- Cancelled memberships

**Purpose:**  
Helps understand the current membership portfolio and customer retention status.

---

### 3. Revenue by Membership Product

A column chart comparing revenue generated by different membership products.

**Purpose:**  
Helps identify the highest-performing membership products.

---

### 4. Top 5 Hotels by Revenue

A chart displaying the top five hotels based on total revenue.

**Purpose:**  
Helps identify the hotels contributing the most revenue to the business.

---

### 5. City Interactive Slicer

An interactive slicer allows users to filter dashboard data by city.

**Purpose:**  
Enables users to explore business performance for individual cities.

---

## 🧮 Data Model

The Power BI data model connects the following tables:

- `member`
- `membership1`
- `bookings`
- `hotels`
- `transaction`
- `entitlements`
- `renewals`

These relationships allow the dashboard to combine membership, booking, hotel, and transaction data for comprehensive analysis.

## 🚀 How to Open the Dashboard

1. Install **Microsoft Power BI Desktop**.
2. Download or clone this repository.
3. Open the `Dashboard` folder.
4. Open:


5. Explore the interactive dashboard and apply the available filters.
