# 🧮 SQL Analysis

This folder contains SQL queries developed to analyze the **Hotel Membership & Booking** relational database.

The analysis focuses on extracting business insights related to members, memberships, bookings, hotels, transactions, renewals, and customer behavior.

---

## 🎯 Objectives

- Practice SQL using real-world business scenarios.
- Analyze data from multiple relational tables.
- Apply SQL concepts to solve business problems.
- Generate meaningful insights from membership, booking, and transaction data.
- Strengthen data analysis and database querying skills.

---

## 🗄️ Tables Used

The SQL analysis uses the following tables:

- `member`
- `membership1`
- `bookings`
- `hotels`
- `transaction`
- `entitlements`
- `renewals`

## 📊 Business Analysis Areas

The SQL queries analyze:

### 👥 Member Analysis

- Total number of members
- Members by subsidiary
- Members with multiple memberships
- Members without memberships
- Members without bookings
- Dormant members

### 💳 Membership Analysis

- Membership count by product
- Membership status distribution
- Active, expired, and cancelled memberships
- Members with multiple memberships
- Memberships without entitlements

### 🏨 Hotel & Booking Analysis

- Total bookings
- Bookings by hotel
- Bookings by city
- Bookings by membership product
- Top hotels by revenue
- Top cities by revenue
- Hotels without bookings

### 💰 Revenue Analysis

- Revenue by payment method
- Revenue by product
- Revenue by subsidiary
- Revenue by hotel
- Top members by revenue
- Average transaction amount
- Average revenue per booking

### 🔄 Renewal & Customer Analysis

- Renewal rate by product
- Churn rate by subsidiary
- Monthly retention analysis
- Top 10% spenders
- RFM customer segmentation
- Customer revenue segmentation
- Month-over-month revenue growth

## 📝 Query Structure

Each SQL problem follows a consistent format:

1. **Problem Number**
2. **Business Question**
3. **SQL Concept**
4. **Tables Used**
5. **Business Purpose**
6. **SQL Solution**

This structure improves readability and makes the analysis easier to understand and maintain.
