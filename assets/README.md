# 🎨 Assets

This folder contains supporting visual assets used for the **Hotel Membership & Booking Analysis** project.

---

## 📌 Purpose

The `assets` folder is used to store images and other visual resources that support the project documentation and presentation.

These assets may include:

- Dashboard screenshots
- Project preview images
- Data visualization images
- Supporting documentation visuals

---

## 📊 Project Visuals

Visual assets can be used to improve the presentation of the project on GitHub and provide a quick overview of the Power BI dashboard and analytical results.

---

## 🗂️ Usage

Assets stored in this folder can be referenced in the main project documentation using Markdown.

Example:

```markdown
![Dashboard Preview](assets/dashboard_preview.png)
```

---

## 📌 Current Status

The folder is reserved for supporting project visuals and presentation assets.

Additional screenshots or visual resources can be added as the project evolves.
